# Escaleras Clavel · web

Web de **Escaleras De Bóveda Clavel S.L.** (Bétera, Valencia): escaleras y bóvedas tabicadas de ladrillo, hechas a mano por la cuarta generación de escaleros.

**En línea:** https://nocodya-hue.github.io/escaleras-clavel/

- Web estática y multipágina: inicio, quiénes somos, los tipos de escalera (a la catalana, de caracol, compensada, al aire y recta), bóvedas, bioconstrucción, presupuesto con preguntas frecuentes, y contacto.
- **Contenido:** sale de su ficha de Google Maps y de su web anterior, escaleras-boveda.com.
- **Fotos:** son de sus obras, mejoradas en color y nitidez y reconstruidas con Real-ESRGAN. Se sirven en AVIF y WebP en varios tamaños.
- **Formulario:** abre WhatsApp con el mensaje escrito, o el correo.
- **SEO:** datos estructurados (HomeAndConstructionBusiness, Service, FAQPage y BreadcrumbList), sitemap y robots.

Hecha por [NOCODYA](https://nocodya.es).
